# ❤️ Love Animation

粒子情书动画 — Matrix 流星雨背景 + 粒子变形文字 + 喷泉爱心

## 运行方式

| 文件 | 使用方式 | 适用 |
|------|---------|------|
| `love_animation.html` | 双击，浏览器打开 | 🌐 全平台（Windows / Mac / 手机） |
| `LoveAnimation.exe` | 双击运行 | 🪟 仅 Windows（无需 Python） |
| `love_animation_v2.py` | `python love_animation_v2.py` | 🐍 需 Python + pygame |
| `love_animation.py` | V1 初版，留档参考 | 🐍 同上 |

## 动画流程

```
粒子团 → 3 → 2 → 1 → Hi 我的宝贝 → 七夕节快乐 → 很想告诉你
→ 你是独一无二的 ❤️ → 爱你胜过一切 → I LOVE YOU → 粒子散开
→ 爱心定格 +「心之所向 爱之所往」
```

- 爱心出现在「你是独一无二的」时，持续至结束
- 背景全程白色 ILOVEYOU 流星雨
- 按 **Esc** 退出（exe/py），浏览器版点画面全屏

## 技术要求

- **HTML 版**：现代浏览器即可，无需安装任何东西
- **exe 版**：Windows 7+，28MB
- **py 版**：Python 3.8+，`pip install pygame`
